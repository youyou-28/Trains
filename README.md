# Projet - _Trains_


Ce projet a lieu dans le cadre des Situations d'Apprentissage et Évaluation du BUT Informatique (SAE S2.01 et S2.02). Il fait intervenir plusieurs compétences acquises durant l'année 2024 : le développement orienté objets, les notions de qualité de développement (tests unitaires, gestion de version, _etc._), les algorithmes de graphes et les interfaces homme-machine.
